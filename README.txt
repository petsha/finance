Business Finance Tracker - installable app (PWA)

1. Upload ALL files in this folder to a web host over HTTPS (for example a GitHub Pages repository).
2. Open the page on the phone.
   Android (Chrome): menu > Install app / Add to Home screen.
   iPhone (Safari): Share > Add to Home Screen.
3. In the old version: Settings > Export backup. In the new app: Settings > Restore backup.
   (Data is stored per app on each device, so it does not move by itself.)
